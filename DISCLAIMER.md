# Disclaimer

**These are teaching tools. They are not medical devices, and they are not for autonomous clinical decision-making.**

Every tool in this repository was built to make a piece of critical-care physiology or diagnostic
reasoning visible and manipulable for clinicians in training. Each one simplifies. Each one encodes
thresholds and cut-points that were derived in specific populations and do not transfer cleanly to
every patient at the bedside.

## What that means in practice

**No tool here is validated for deployment.** None has been externally validated, none is FDA-cleared,
and none has been tested prospectively against clinical outcomes. Several encode values that are
explicitly labelled in the tool itself as derived, synthesized, or consensus rather than directly
reported. Those labels are load-bearing; read them.

**Thresholds are risk-stratifiers, not treatment targets.** Where a tool draws a line, that line
usually comes from a study reporting an association with an outcome. Almost none of these lines has
been shown in a randomized trial to improve anything when used as a target. A number that predicts a
worse outcome is not the same as a number worth chasing.

**Population matters more than the interface suggests.** A cut-point derived in adult septic shock
does not become pediatric because a pediatric patient is in front of you. Where a tool knows the
population its numbers came from, it says so.

**No patient data should be entered.** These pages run entirely in the browser. Nothing is stored on a
server and nothing is transmitted. That is a reason not to worry about the values you type; it is not
a reason to type protected health information into a public web page.

## Clinical judgment governs

Defer to your own assessment, your institution's protocols, and current guidelines. If a tool here
disagrees with any of those, the tool is the thing that is wrong.

## Reporting a problem

If you find an error — a wrong threshold, a misattributed citation, a claim that current evidence no
longer supports — please open an issue. Corrections to clinical content are the most useful
contribution anyone can make to this repository.
